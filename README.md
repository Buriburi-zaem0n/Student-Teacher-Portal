# Student-Teacher-Portal
A full-stack web application designed to improve interaction and academic workflow between students and teachers. The platform offers role-based access, allowing teachers to manage academic activities while students can access course-related information from a single dashboard.

Features:
Secure student and teacher authentication
Separate dashboards for students and teachers
Assignment creation, submission, and tracking
Attendance management
Announcements and notices
Student performance and record management
Responsive and user-friendly interface

Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: php
Database: SQL
Security: PDO prepared statements


Purpose:
This project was built to explore full-stack web development concepts, including authentication, database management, role-based access control, and CRUD operations  while solving a real-world academic management problem.
